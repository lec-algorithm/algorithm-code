# 05. 최단 경로 (간선 k개)

방향 그래프에서 **간선을 정확히 k개** 써서 `u`에서 `v`로 가는 가장 싼 길을
구한다. 첫 간선 `u -> x`를 고르면 남은 일은 `x`에서 `v`로 간선 `k-1`개로
가는 같은 문제다. 메모 표에 답과 함께 **가장 싼 첫 걸음**(`next`)을 적어
두었다가, 답을 낸 뒤 그것을 따라가 길을 복원한다.

그래프는 정점 6개(0\~5), 간선 9개다. 간선 목록은 실행 결과의 첫 줄에 있다.

| 파일 | 내용 |
| --- | --- |
| `shortestPath.pseudo` | 점화식, 메모이제이션, 경로 복원 |
| `shortestPath.c` | C 구현 |
| `shortest_path.py` | Python 구현 |

## 실행

파일을 열고 편집기 오른쪽 위 **▶ 버튼**을 누릅니다. C와 Python 모두 됩니다.

터미널에서 직접 돌리려면 이렇게 합니다.

- 실행

```sh
cd src/topic-14-dynamic-programming/05_shortest_path
make -f /work/Makefile shortestPath.out && ./shortestPath.out
python3 shortest_path.py
```

- 결과

```console
edges: 0->1 (1), 0->2 (2), 1->3 (6), 2->1 (2), 2->3 (4), 2->4 (3), 3->5 (3), 4->3 (1), 4->5 (5)
0 -> 3 with exactly 3 edges

plain recursion = 6, calls = 12
  hit memo[1][3][3] = INF
memo            = 6, calls = 11
  k=1: 1->3 = 6, 3->3 = INF, 4->3 = 1
  k=2: 1->3 = INF, 2->3 = 4
  k=3: 0->3 = 6
path: 0 -> 2 -> 4 -> 3 (2 + 3 + 1 = 6)
```

두 구현이 같은 결과를 낸다.

- `0 -> 3`을 간선 3개로 가는 길은 `0 -> 2 -> 4 -> 3`(6)과 `0 -> 2 -> 1 -> 3`(10)
  두 가지다. `0 -> 1`로 시작하면 1에서 3으로 간선 2개로 갈 수 없다(`INF`).
- `k=2: 2->3 = 4`는 2에서 3으로 간선 2개로 가는 가장 싼 비용이다.
  `2 -> 1 -> 3`은 2 + 6 = 8, `2 -> 4 -> 3`은 3 + 1 = 4다.
- `3->3`을 간선 1개로 가는 길은 없다(`INF`). 이 칸은 두 번 필요했고,
  두 번째는 표에서 꺼냈다(`hit`).
- 그래프가 작아 호출 수는 12번과 11번으로 거의 같다. 이 예제의 요점은
  표 한 칸이 **부분 문제 하나**라는 것과, 표에서 길을 되살리는 방법이다.

## 바꿔 보기

- `k`를 2로 바꿔 보자. `0 -> 2 -> 3`(6)이 나온다. 4로 바꾸면 3에 간선
  4개로 닿는 길이 없어 `no path`다.
- 도착점을 5로, `k`를 4로 바꿔 보자. `0 -> 2 -> 4 -> 3 -> 5`(9)가 나온다.
