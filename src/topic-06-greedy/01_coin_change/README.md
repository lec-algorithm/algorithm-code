# 01. 동전 거스름돈 (Coin Change)

정해진 금액을 가장 적은 수의 동전으로 만드는 문제.
언제나 남은 금액 이하의 **가장 큰 동전부터** 낸다. 그리디의 가장
단순한 예다. 같은 절차를 의사코드 하나에 C와 Python 두 구현으로 담았다.

| 파일 | 내용 |
| --- | --- |
| `coinChange.pseudo` | 기준이 되는 절차. 두 구현은 이것을 옮긴 것이다 |
| `coinChange.c` | C 구현 |
| `coin_change.py` | Python 구현 |

## 실행

파일을 열고 편집기 오른쪽 위 **▶ 버튼**을 누릅니다. C와 Python 모두 됩니다.

터미널에서 직접 돌리려면 이렇게 합니다.

- 실행

```sh
cd src/topic-06-greedy/01_coin_change
make -f /work/Makefile coinChange.out && ./coinChange.out
python3 coin_change.py
```

- 결과

```console
coins = {500, 100, 50, 10}, amount = 1260
greedy: 500x2 100x2 50x1 10x1 -> 6 coins

coins = {50, 40, 10}, amount = 80
greedy: 50x1 10x3 -> 4 coins
```

두 구현이 같은 결과를 낸다. 첫 줄은 최적이다. 둘째 줄은 아니다.
40원 두 개면 **2개**로 끝나는데, 그리디는 50원을 먼저 집는 바람에
4개를 썼다. 절차는 같고 동전 단위만 바뀌었다.

## 바꿔 보기

`{500, 100, 50, 10}`에서 금액을 여러 가지로 바꿔 보자. 언제나 최적이다.
큰 단위가 작은 단위의 배수라서 그렇다. `{50, 40, 10}`처럼 그 관계가
깨지면 최적이 깨지는 금액이 생긴다. 어떤 금액에서 깨지는지 찾아보자.
