# 02. 이진 검색 (Binary Search)

**정렬된** 배열에서 가운데를 보고 남은 범위를 절반으로 줄여 나가는 검색.
한 번 비교할 때마다 후보가 반으로 줄어드니 O(log n)이다.

| 파일 | 내용 |
| --- | --- |
| `binarySearch.pseudo` | 기준이 되는 절차 |
| `binarySearch.c` | C 구현 |
| `binary_search.py` | Python 구현 |

## 실행

파일을 열고 편집기 오른쪽 위 **▶ 버튼**을 누릅니다.

- 결과

```console
n = 15, key = 51
index = 6, comparisons = 4
```

같은 배열, 같은 key를 [01_sequential_search](../01_sequential_search/)로 찾으면
비교가 7회입니다. 여기서는 4회입니다.

## 바꿔 보기

- `key`를 배열에 없는 값(예: `50`)으로 바꾸면 몇 번 비교하고 `-1`을 돌려주는지
- **배열을 뒤섞어 보세요.** 정렬을 전제로 하므로 답이 틀립니다. 순차 검색은
  정렬과 무관하게 맞는 답을 냅니다. 이진 검색이 빠른 대신 요구하는 조건입니다.

## 왜 `lo + (hi - lo) / 2`인가

`(lo + hi) / 2`가 더 읽기 쉽지만, 두 값이 클 때 덧셈에서 자료형의 범위를
넘어설 수 있습니다. 위 형태는 그 문제가 없습니다.
