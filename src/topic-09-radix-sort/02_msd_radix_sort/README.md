# 02. MSD 기수 정렬 (MSD Radix Sort)

**가장 높은 자리부터** 카운팅 정렬로 버킷을 나누고, 원소가 둘 이상인
버킷만 다음 자리로 재귀한다. 높은 자리에서 이미 갈린 원소는 다시 보지
않는다. 같은 절차를 의사코드 하나에 C와 Python 두 구현으로 담았다.

| 파일 | 내용 |
| --- | --- |
| `msdRadixSort.pseudo` | 기준이 되는 절차. 두 구현은 이것을 옮긴 것이다 |
| `msdRadixSort.c` | C 구현 |
| `msd_radix_sort.py` | Python 구현 |

## 실행

파일을 열고 편집기 오른쪽 위 **▶ 버튼**을 누릅니다. C와 Python 모두 됩니다.

터미널에서 직접 돌리려면 이렇게 합니다.

- 실행

```sh
cd src/topic-09-radix-sort/02_msd_radix_sort
make -f /work/Makefile msdRadixSort.out && ./msdRadixSort.out
python3 msd_radix_sort.py
```

- 결과

```console
input : 170 045 075 090 002 802 024 066
exp 100 [0..7]: 045 075 090 002 024 066 170 802
  buckets: 0=6 1=1 8=1
  exp 10  [0..5]: 002 024 045 066 075 090
    buckets: 0=1 2=1 4=1 6=1 7=1 9=1
sorted: 002 024 045 066 075 090 170 802
digits examined = 14 (LSD: 8 x 3 = 24)
```

두 구현이 같은 결과를 낸다. 들여쓰기가 재귀 깊이다. 백의 자리로 나누면
버킷 0에 여섯 개, 버킷 1과 8에 하나씩 들어간다. 하나뿐인 `170`과 `802`는
그 자리에서 끝난다. 버킷 0만 십의 자리로 다시 나누는데, 거기서 모든
버킷이 크기 1이 되므로 **일의 자리는 아예 보지 않는다**. 자리를 읽은
횟수는 8 + 6 = 14번으로, 모든 원소의 모든 자리를 읽는 LSD의 24번보다 적다.

## 바꿔 보기

`a`를 `{111, 112, 113, 114}`처럼 앞자리가 모두 같은 값으로 바꿔 보자.
첫 두 자리에서 버킷이 하나로 모여 갈리지 않으므로 모든 자리를 끝까지
본다. MSD의 최악이다. 반대로 `{100, 200, 300, 400}`이면 첫 자리에서 모두
갈려 재귀가 일어나지 않는다.
